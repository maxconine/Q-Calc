About Q Calc

I was constantly frustrated at the lack of features in the Spotlight search calculator. It didn't save my history, so I'd lose previous expressions and calculations. It was also not optimized for scientific calculations. It couldn't solve equations, define variables, or evaluate integrals or summations. I knew I could develop something that solved this and was purpose built for people with a STEM background.

After an initial round of developing, I showed it to a few friends and they helped invent new features to make evaluating expressions while working as quick and easy as possible. We added significant figures, so an answer rounds to the correct number automatically. We added uncertainty, so a sum of values can carry the uncertainty of each one. Every feature was purpose built for the student, to make quick calculations faster than ever before.

Introducing Q Calc: Spotlight search calculator, but better.
