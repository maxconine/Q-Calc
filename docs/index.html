download

Mac: Apple silicon (M1 or later) and macOS 14 or later.

Download Q Calc 2.0.6 for Mac. Unzip it and move Q Calc.app to Applications. If macOS blocks the first open, use System Settings → Privacy & Security → Open Anyway.

Windows: Windows 10 or 11.

Download Q Calc 2.0.6 for Windows (or the Arm version for Snapdragon PCs). Run the installer; it doesn’t need admin rights, and Q Calc updates itself after that. If Windows says it protected your PC, click More info → Run anyway.

after you install

Mac: Control + Option + Space opens the calculator. Press 'Command ,' to open settings.

If the shortcut does nothing, macOS is often using it for Input Sources. Turn that off in System Settings → Keyboard → Keyboard Shortcuts → Input Sources.

Windows: Alt + Space opens the calculator. Press Ctrl + , to open settings. Q Calc lives in the notification area (under ^ on the taskbar) and starts when you sign in.

If Alt + Space opens something else, like PowerToys Run, choose another key under Keybinds in settings.
