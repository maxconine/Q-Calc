Download

Apple silicon (M1 or later) and macOS 14 or later.

Homebrew Install (recommended)

You need Homebrew.

/bin/zsh -c "$(curl -fsSL https://raw.githubusercontent.com/maxconine/Q-Calc/main/macos/install.sh)"

Zip Download

Download Q Calc 2.0.2. Unzip it and move Q Calc.app to Applications. If macOS blocks the first open, use System Settings → Privacy & Security → Open Anyway.

After you install

Control + Option + Space opens the calculator.

Press 'Command ,' to open settings.

If the shortcut does nothing, macOS is often using it for Input Sources. Turn that off in System Settings → Keyboard → Keyboard Shortcuts → Input Sources.
