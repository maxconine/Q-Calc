Q(uick) Calc

I was constantly frustrated at the lack of features in the Spotlight search calculator. It didn't save my history, so I'd lose previous expressions and calculations. It was also not optimized for scientific calculations. It couldn't solve equations, define variables, or evaluate integrals or summations. I knew I could develop something that solved this and was purpose built for people with a STEM background.

After an initial round of developing, I showed it to a few friends and they helped invent new features to make evaluating expressions while working as quick and easy as possible. We added significant figures, so an answer rounds to the correct number automatically. We added uncertainty, so a sum of values can carry the uncertainty of each one. Every feature was purpose built for the student, to make quick calculations faster than ever before.

Introducing Q Calc: Spotlight search calculator, but better.

Download

Apple silicon (M1 or later) and macOS 14 or later.

Homebrew Install (recommended)

If you want automatic updates. You need Homebrew.

brew tap maxconine/qcalc https://github.com/maxconine/Q-Calc
brew trust --tap maxconine/qcalc
brew install --cask maxconine/qcalc/q-calc
zsh "$(brew --prefix)/Library/Taps/maxconine/homebrew-qcalc/macos/enable-autoupdate.sh"

Or paste this into Terminal:

/bin/zsh -c "$(curl -fsSL https://raw.githubusercontent.com/maxconine/Q-Calc/main/macos/install.sh)"

Zip Download

You can also download the current version directly from this website as a Zip file.

Download Q Calc 2.0.1 (.zip). Unzip it and move Q Calc.app to Applications. If macOS blocks the first open, use System Settings → Privacy & Security → Open Anyway.

Other builds are on the releases page.

After you install

Look for the icon in the menu bar. Control + Option + Space opens the calculator. Esc or a click outside hides it.

Press 'Command ,' to open settings. There you can change the hotkey that opens the app, along with the other configurations.

If the shortcut does nothing, macOS is often using it for Input Sources. Turn that off in System Settings → Keyboard → Keyboard Shortcuts → Input Sources.
