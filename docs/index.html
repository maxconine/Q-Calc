Q Calc

A scientific calculator for Mac that shows up like Spotlight. Press Control + Option + Space, type, and the answer updates as you type. The app lives in the menu bar.

Try sin(90), 72 f, 2 in to cm, graph x^3, or $10 for lunch + 15% tip.

It handles the usual scientific functions, unit conversions, variables, functions, graphs, and small systems of equations.

Download

Apple silicon (M1 or later) and macOS 14 or later. Q Calc is not notarized. Homebrew removes the quarantine flag, so the app opens without the “Apple cannot check this for malicious software” warning.

Homebrew

This is the way to get daily updates. You need Homebrew.

brew tap maxconine/qcalc https://github.com/maxconine/Q-Calc
brew trust --tap maxconine/qcalc
brew install --cask maxconine/qcalc/q-calc
zsh "$(brew --prefix)/Library/Taps/maxconine/homebrew-qcalc/macos/enable-autoupdate.sh"

Or paste this into Terminal:

/bin/zsh -c "$(curl -fsSL https://raw.githubusercontent.com/maxconine/Q-Calc/main/macos/install.sh)"

Zip

Download Q Calc 2.0.1 (.zip). Unzip it and move Q Calc.app to Applications. If macOS blocks the first open, use System Settings → Privacy & Security → Open Anyway.

Other builds are on the releases page.

After you install

Look for the icon in the menu bar. Control + Option + Space opens the calculator. Esc or a click outside hides it.

If the shortcut does nothing, macOS is often using it for Input Sources. Turn that off in System Settings → Keyboard → Keyboard Shortcuts → Input Sources.
